            Connections

            Keys the website needs to publish and to send email. They are stored encrypted and never shown again after you save them. Only the super admin can see this tab.

            Signing in

            Switch this on once an owner can sign in with an email and password. Then the master password on its own no longer works at the login page. If nobody can sign in, add ADMIN_MASTER_LOGIN=on in Vercel to bring it back.

            Publishing (GitHub)

            Create a fine-grained key at github.com → Settings → Developer settings → Fine-grained tokens. Give it only the website repository, with "Contents: Read and write".
